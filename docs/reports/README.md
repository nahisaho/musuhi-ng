## Report Template

All phase completion reports follow this structure:

1. **Executive Summary**
   - Overall achievement metrics
   - Test coverage summary
   - Key accomplishments

2. **Feature-by-Feature Analysis**
   - Acceptance criteria status
   - Key components delivered
   - Performance achievements
   - Architecture highlights

3. **Architecture & Design Highlights**
   - ADR summary
   - Constitutional compliance
   - Design patterns used

4. **Quality Metrics**
   - Test coverage analysis
   - Code quality metrics
   - Performance benchmarks
   - Requirements traceability

5. **Known Issues & Limitations**
   - Minor issues (non-blocking)
   - Technical debt identified
   - Limitations by design

6. **Next Steps & Recommendations**
   - Immediate priorities
   - Recommended approach
   - Technical debt resolution
   - Documentation priorities

7. **Risk Assessment**
   - Low/medium/high risk items
   - Mitigation strategies

8. **Conclusion**
   - Key achievements
   - Recommendations
   - Project status

## Document Conventions

- **Language**: All reports are bilingual (English `.md` + Japanese `.ja.md`)
- **Versioning**: Each report includes version, date, author, status
- **Traceability**: All reports link to requirements, design, tasks, ADRs
- **Metrics**: Quantitative data for test coverage, LOC, performance
- **Visualization**: Progress indicators using markdown tables and checkboxes
